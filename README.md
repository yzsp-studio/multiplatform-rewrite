## 🇨🇳 中文

这个技能把已有素材改写成可发布的多平台分发版本，母稿、文章、新闻稿、活动稿、产品稿、报告摘要、访谈素材、口播稿、散乱素材都能作为输入。标准场景是 2 个及以上平台，也支持有素材的单平台改写，覆盖微信公众号、短视频脚本、微博等。动手前先跑使用边界判断流程，按优先级依次检查，命中即停止，明确区分应使用与不应使用场景，并给出边界回复策略与复合场景交叉策略。最终必须创建并交付飞书文档。

### ✨ 能做什么

- 输入母稿 → 输出多平台分发执行包（公众号版 + 短视频脚本 + 微博版等）
- 按平台改语气、篇幅与结构，不是同一篇复制粘贴
- 先跑边界判断流程，命中即停止：单平台从零创作、论文写作等直接判定不适用
- 散乱素材、访谈口播稿先整理成稿，再按平台分发
- 复合场景有交叉策略，多平台要求一次覆盖
- 最终交付飞书文档，可直接进入发布流程

## 🇬🇧 English

This skill rewrites material you already have into publishable, per-platform versions—master draft, article, press release, event copy, product copy, report summary, interview notes, voice-over script, or loose fragments. The standard case is two or more platforms, and single-platform rewriting with source material is supported too, covering WeChat official accounts, short-video scripts, Weibo, and more. Before writing it runs a boundary check in priority order and stops on the first hit, clearly separating in-scope from out-of-scope requests and defining both a boundary reply strategy and a cross-strategy for mixed requests. The deliverable is always a Lark doc.

### ✨ What it does

- Master draft in, distribution pack out: WeChat version plus short-video script plus Weibo version
- Rewrites tone, length, and structure per platform instead of copy-pasting one text
- Runs a boundary check first and stops on the first hit, rejecting from-scratch single-platform work and academic writing
- Tidies loose fragments and interview or voice-over material into a draft, then splits it per platform
- Cross-strategy handles mixed requests so multi-platform asks are covered in one pass
- Always delivers a Lark doc, ready for the publishing flow
